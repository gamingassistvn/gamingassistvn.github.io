Privacy Policy for T11 Auto Helper

Effective Date: October 2026 | Last Updated: October 07, 2026

1. Purpose of the Application

T11 Auto Helper is an automation utility designed to help users streamline repetitive tasks on Android devices.

2. Use of Android AccessibilityService API

T11 Auto Helper utilizes the Android AccessibilityService API strictly for automation tasks configured and triggered by the user:

  • Automated Gestures: Simulating screen taps, swipes, and key inputs per user-defined automation scripts.
  • No Personal Data Harvesting: The Accessibility Service does NOT read, capture, transmit, or store keystrokes, personal passwords, banking information, or private messages.
  • User Consent: The service is inactive until explicitly enabled by the user in Android System Settings, and can be revoked at any time.

3. Data Storage & Permissions

All custom automation scripts, schedules, and preferences are stored exclusively on your device. We do not transmit script data to external servers.
